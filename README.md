# This and That — Interactive OVA

An interactive Online Learning Object (OVA) for **Path 3: Plan It**, designed to accompany the Grade 2 EFL lesson *Interactive Storytelling: This and That*.

## Learning route

1. **Look & Predict** — observe the characters and make a prediction.
2. **Story Time** — predict what Bekku may do when she sees a mouse.
3. **Put It in Order** — choose story events and discuss their sequence with the teacher.
4. **What Do You Like?** — connect the story with personal preferences using “I like …”.
5. **Finish the Story** — identify what Bekku and the girl have in common.

## Run locally

Open `index.html` in a modern browser. The OVA is self-contained and does not require a build step or external libraries.

## Publish with GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml`.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open **Actions** and check the **Deploy OVA to GitHub Pages** workflow.
4. Once the deployment succeeds, open the published URL shown in the workflow's deployment environment. It should follow this pattern: `https://willixmaa.github.io/path3-this-and-that-ova/`.

## About the resource

- Audience: Grade 2 English as a Foreign Language (EFL) learners.
- Lesson: *Interactive Storytelling: This and That* (Path 3: Plan It).
- Learning focus: story comprehension, prediction, sequencing, and expressing preferences.
- The visuals are symbolic emoji-based placeholders, not original artwork from the book. Replace them only with illustrations you have permission to use.
- The sequence activity is intended to be discussed and checked with the teacher against the original story illustrations.
